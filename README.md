# The North artefact

Losse site bij mijn North artefact, de kaleidoscoop, voor de minor Next Gen Leadership (NHL Stenden). Zelfde stijl als mijn portfolio Finding North.

- De tekst staat letterlijk in `index.html`.
- Opmaak in `assets/style.css`; licht/donker en de fotoviewer in `assets/site.js`.
- Foto (Figure 1) in `fotos/figure-1-kaleidoscope-card.jpg`.

Bekijken: open `index.html` in de browser. De lettertypes komen van Google Fonts.
